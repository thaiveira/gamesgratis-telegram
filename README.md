# Games grátis bot
Bot para canal de divulgação de jogos grátis no telegram.

O que faz: busca jogos temporariamente 100% grátis (Steam, Epic, GOG, itch.io, etc.)
e publica em um canal do Telegram, sem repetir o que já foi enviado.

Fonte de dados: GamerPower API (https://www.gamerpower.com/api-read)
